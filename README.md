# Movie Ticket Booking Calculator

A comprehensive Python application designed to calculate movie ticket pricing and verify booking eligibility based on multiple complex conditions. 

This project demonstrates advanced conditional logic, nested statements, and logical operators.

## 🚀 Features
* Verifies general and evening show booking eligibility based on user age and membership status.
* Evaluates multiple conditions using short-circuit logical operators (`and`, `or`, `!=`).
* Dynamically calculates ticket discounts for eligible members.
* Applies dynamic extra charges for evening and weekend showtimes.
* Uses nested `if-elif-else` structures to determine seating-specific service charges (Premium, Gold, Standard).
* Outputs precise terminal summaries of costs, charges, and the final ticket price.

## 🧠 Concepts Learned
* **Boolean Logic:** Managing true/false flags (`True`, `False`).
* **Conditional Structures:** Deep nesting with `if`, `elif`, and `else` blocks.
* **Logical Expressions:** Combining operators (`and`, `or`, `not`) with parentheses `()` to enforce correct evaluation order.
* **Variable Updating:** Dynamically modifying numeric state across separate logical steps.

## 🛠️ How to Run
Ensure you have Python installed on your local system, then run:
```bash
python main.py
```
